# 検品結果 1120（1ページ構成への作り直し・index.html）

対象：index.html（SAT紹介＋無料ガイド）／shikaku.html（転送）／退避の影響
比べた物：index_旧5.html（組み替え前）・退避したページ群・公開中の本番サイト

## 要修正（2つ・どちらも「公開」まわり）
### 1. 本番にはまだ反映されていない
`git log origin/main..HEAD` を見ると、**未pushのコミットが4つ**（教材3本目／1ページに絞る／ガイドの節／転職ページをやめる）。さらに **index.html は未コミット**（`git status` で M）、`index_旧5.html` は未追跡です。
実際に本番を見にいくと、入口はまだ旧版（タイトル「現場のてつ先輩｜転職と資格の入口」）で、退避したページも全部 **200 で生きています**（sat.html／guide.html／ranking.html／tenshoku.html／torikata.html／shikaku-otsu4.html ほか、確認済み）。
→ 「公開は1ページだけにした」という状態には**まだなっていません**。本人に見せる前に、ここの認識を合わせてください。

### 2. push した瞬間に、9ページが404になる
退避したのは guide／ichiran／ranking／sat／torikata／shikaku-otsu4／shikaku-eisei／shikaku-denki2／tenshoku の**9本**。転送ページを用意したのは **shikaku.html だけ**です。
これらは**すでに本番で公開されていたURL**なので、投稿・DM・プロフィールに貼っていれば行き止まりになります。特に注意：
- **sat.html**（A8リンクが載っていたページ。ここを踏んでもらう導線だった）
- **guide.html**（無料ガイドの受け取り方。DMで案内した可能性）
- **tenshoku.html**（長く公開していた転職ページ）
→ 同じ形の転送ページを置くか、**どのURLを投稿に貼ったかを確認**してから push するのが安全です。
